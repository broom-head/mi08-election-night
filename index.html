How it works, in plain terms

1. The counties publish resultsEach county clerk posts election-night numbers on its own website, in its own format. Saginaw, Midland, Genesee, Oakland and Macomb use results websites that also publish the numbers as a machine-readable data file (called JSON: the same numbers a person sees on the page, but in a form a program can read exactly). Tuscola posts a plain web page (HTML) with a table of precinct results. Bay posts a PDF with every precinct, the kind of document a clerk prints.
2. A laptop collects themA small program on John's laptop (the relay) visits every county site once a minute, the way a browser would, keeps only what has changed since last time, and sends it all in one package to the poller. On election night the Mac's scheduler (launchd) starts it automatically every minute. Pressing Run now below asks for an extra pass right away.
3. The poller writes the sheetThe poller is a Google Apps Script, a program that lives inside Google and is allowed to edit the tracker sheet. It reads each county's numbers, matches each county precinct to its row in the tracker, writes election-day, absentee and early-vote counts for each candidate, then re-reads every cell it wrote to confirm it landed. Numbers typed by hand from tapes are never overwritten. Every run is written to a log sheet.
4. The sheet and the board updateThe tracker's own formulas (benchmarks, dashboard, margins) recalculate as cells land. The results board reads the sheet every minute and shows the same numbers in a bigger, clearer form.
